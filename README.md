# Bionix Community · Android

Instalador oficial de la app **Bionix Community** para Android.
El código de la app no está aquí; este repositorio solo sirve para descargarla.

**[⬇️ Descargar la app (bionix.apk)](https://github.com/jamalmkt/bionix-android/releases/latest/download/bionix.apk)**

## Cómo instalarla
1. Abre el enlace desde tu móvil Android y descarga el archivo.
2. Ábrelo. Si Android te avisa, pulsa **Ajustes → Permitir de esta fuente** y vuelve atrás.
3. Pulsa **Instalar** y entra con el email y la contraseña que te enviamos por correo.

La app se actualiza sola; no hace falta volver a descargarla.
